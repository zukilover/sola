# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
version 2.1.

In short: be respectful, assume good faith, and do not harass anyone. The
maintainers may reject contributions or ban people who make this project
unsafe to work in.

Report conduct issues privately using the contact in [SECURITY.md](./SECURITY.md).
Do not use the public issue tracker for that.
